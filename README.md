# HR Employee Attrition Dashboard

## Project Overview

This project analyzes employee attrition data to identify the key factors influencing employee turnover. An interactive dashboard was developed using Tableau to help HR teams understand attrition patterns and make data-driven decisions.

## Objective

The primary objective of this project is to:

* Analyze employee attrition trends.
* Identify factors contributing to employee turnover.
* Provide actionable insights for improving employee retention.
* Create an interactive dashboard for HR decision-making.

## Tools Used

* Tableau
* CSV Dataset
* Data Visualization
* Exploratory Data Analysis (EDA)

## Dataset Information

Dataset: IBM HR Analytics Employee Attrition Dataset

The dataset contains employee information including:

* Age
* Gender
* Department
* Job Role
* Monthly Income
* Overtime
* Marital Status
* Job Satisfaction
* Work-Life Balance
* Attrition Status

## Dashboard Features

### KPI Cards

* Total Employees
* Attrition Count
* Attrition Rate (%)
* Average Monthly Income

### Interactive Visualizations

* Attrition by Department
* Attrition by Job Role
* Attrition by Age Group
* Overtime Impact on Attrition
* Job Satisfaction vs Attrition
* Work-Life Balance vs Attrition

### Interactive Filters

* Department
* Gender
* Job Role
* Marital Status
* Age Group

## Key Findings

* Employees working overtime show significantly higher attrition rates.
* Employees aged 18–35 are more likely to leave the organization.
* Lower job satisfaction is strongly associated with employee turnover.
* Employees with poor work-life balance have higher attrition rates.
* Certain job roles experience greater turnover than others.

## Business Recommendations

1. Reduce excessive overtime where possible.
2. Improve employee engagement programs.
3. Focus retention strategies on younger employees.
4. Conduct regular job satisfaction surveys.
5. Promote better work-life balance initiatives.
